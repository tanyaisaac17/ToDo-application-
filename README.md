# 📝 TaskFlow — Todo List App

## 🎯 Project Title and Objective

**Title:** TaskFlow — Client-Side Todo List Application

**Objective:** To build a functional, responsive Todo List application that runs entirely in the browser using HTML, CSS and JavaScript — with no backend or database required. The goal was to practice DOM manipulation, event handling, and data persistence using localStorage.

---

## 📄 Project Description

TaskFlow is a clean and responsive client-side Todo List web app that helps users organize and track their daily tasks. It includes a personalized login screen where users enter their name to access their own task space. All tasks are stored in the browser using localStorage, so data is never lost even after closing or refreshing the page.

Users can add tasks, mark them as complete, delete them, and filter by status. A live progress bar and stats panel give a clear overview of daily productivity.

---

## ✨ Features

- Name-based login screen
- Add tasks by clicking a button or pressing Enter
- Mark tasks as complete / pending using a checkbox
- Delete individual tasks
- Filter tasks by All, Active or Completed
- Progress bar showing completion percentage
- Stats panel — Total, Remaining and Completed tasks
- Friendly empty state messages
- Data saved using localStorage — persists after browser close
- Fully responsive on mobile and desktop

| Technology | Purpose |

## ⚙️ Setup Instructions

This project requires no installation or dependencies. It runs entirely in the browser.
1. Clone the repository
bashgit clone https://github.com/tanyaisaac17/ToDo-application-.git
cd ToDo-application-
2. Open the project
Simply open index.html in any modern web browser. No build steps or server required.
Alternatively, if you're using VS Code or Cursor, you can use the Live Server extension for a better development experience:

Install the Live Server extension
Right click index.html → Open with Live Server
The app will open at localhost:5500 and auto-refresh on save

3. That's it!
The app will load instantly. Your tasks are automatically saved to your browser's localStorage.
