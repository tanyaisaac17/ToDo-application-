# ToDo List
📝 Todo-List
A simple and clean Todo List web app where you can manage and track your daily tasks.

🔗 Live Demo

✨ Features

Name-based login so the app feels personal
Add tasks quickly by typing and pressing Enter
Mark tasks as complete with a checkbox
Delete tasks you no longer need
Filter tasks by All, Active, or Completed
Progress bar to track how much you've done
Stats panel showing total, remaining and completed tasks
Friendly empty state messages
Data saved in localStorage — tasks stay even after closing the browser
Fully responsive on mobile and desktop


🛠️ Tech Stack
Client: HTML5, CSS3, Vanilla JavaScript
Storage: localStorage API
Server: GitHub Pages

🚀 How to Run
Open the project directly in your browser — no installation needed.
bashgit clone https://github.com/tanya/Todo-List.git
cd Todo-List
open index.html

📖 Usage/Examples
This app can be used to write your daily tasks and monitor them. Just enter your name on the login screen, start adding tasks, and check them off as you go.
